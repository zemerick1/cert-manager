      In Cloudflare, open My Profile, then API Tokens, then Create Token. Give the token Zone DNS Edit and Zone Zone Read, and include the zone that owns the certificate name. Do not use the Global API Key.

      ClearPass

      Not saved

      Create the API client on the publisher before saving it here. This page cannot create that client.

      1. Open Administration, then API Services, then API Clients, then Add.
      2. Set Operating Mode to ClearPass REST API and Grant Type to Client Credentials.
      3. Choose an operator profile that can manage server certificates and the trust list. Super Administrator is the profile that has those rights.
      4. Save the client, then Generate New Secret. Copy the secret now. ClearPass shows it once.

      One hostname per line. Deploy logs into the publisher and installs the certificate on every server the cluster API returns, then contacts each name here the same way.
